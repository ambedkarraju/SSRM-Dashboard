One-time setup (only needed once, ever): for a new unit created here to appear on the live dashboard, your Supabase business_units table needs a dashboard_active boolean column. If you haven't added it yet, run this once in the Supabase SQL Editor: 
ALTER TABLE business_units ADD COLUMN IF NOT EXISTS dashboard_active boolean NOT NULL DEFAULT false;

UPDATE business_units SET dashboard_active = true WHERE code IN (
  'BNPL_HYDERABAD','BPC_BOLLARAM','BPC_DR_BRAOU','BPC_JEEDIMETLA',
  'HYDERABAD_DECCAN_RS_TMO','PBC_AUTONAGAR','NSH_COUNTER','SECUNDERABAD_RS_TMO',
  'NAMPALLY_HYDERABAD_BPC_II','BPC_DEVARAYAMJAL_I_II','BPC_POCHARAM','PBC_AUTONAGAR_COUNTER'
);
Until you run this, new units created below will still save to the database, but the dashboard and upload dropdown will fall back to the original 12-unit list. This form works either way.
